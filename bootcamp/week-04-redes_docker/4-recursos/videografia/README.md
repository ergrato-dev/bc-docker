# 🎬 Videografía - Redes en Docker

Videos y tutoriales recomendados para aprender networking en Docker.

---

## 🎥 Videos Esenciales

### 1. Docker Networking Crash Course

- **Canal**: TechWorld with Nana
- **Duración**: ~25 minutos
- **URL**: [YouTube](https://www.youtube.com/watch?v=bKFMS5C4CG0)
- **Contenido**:
  - Tipos de redes Docker
  - Creación y gestión
  - Comunicación entre contenedores
- **Nivel**: Principiante
- **Idioma**: Inglés

### 2. Container Networking From Scratch

- **Canal**: KodeKloud
- **Duración**: ~40 minutos
- **URL**: [YouTube](https://www.youtube.com/results?search_query=docker+networking+kodekloud)
- **Contenido**:
  - Network namespaces
  - Virtual ethernet
  - Bridge networking
- **Nivel**: Intermedio
- **Idioma**: Inglés

### 3. Docker Networking Deep Dive

- **Canal**: Docker Official
- **Duración**: ~1 hora
- **URL**: [Docker YouTube](https://www.youtube.com/c/DockerInc)
- **Contenido**:
  - Arquitectura interna
  - Overlay networks
  - Troubleshooting
- **Nivel**: Intermedio-Avanzado
- **Idioma**: Inglés

## 💡 Tips para Aprender con Videos

1. **Velocidad 1.25x-1.5x**: Ajusta según tu nivel
2. **Pausa y practica**: No solo mires, ejecuta los comandos
3. **Subtítulos**: Actívalos si el inglés no es tu fuerte
4. **Toma notas**: Anota comandos y conceptos clave
5. **Repite**: Los conceptos de red requieren repetición
