## 📋 Lista de Reproducción Sugerida

### Orden recomendado para esta semana

1. **Introducción a gestión de contenedores** (~15 min)
2. **Docker run y opciones** (~20 min)
3. **Ciclo de vida: start, stop, restart** (~10 min)
4. **Docker logs y debugging** (~15 min)
5. **Variables de entorno** (~12 min)
6. **Límites de recursos** (~15 min)
7. **Docker exec y attach** (~12 min)

**Tiempo total estimado:** ~1.5 horas

## 🎯 Tips para Aprovechar los Videos

1. **Practica mientras miras**: Ten una terminal abierta
2. **Pausa y replica**: No solo mires, ejecuta los comandos
3. **Toma notas**: Anota los comandos nuevos
4. **Velocidad 1.25x**: Si ya conoces el tema, acelera
5. **Activa subtítulos**: Útil para videos en inglés

## 📱 Apps para Ver Offline

| App             | Plataforma  | Función                  |
| --------------- | ----------- | ------------------------ |
| YouTube Premium | iOS/Android | Descargar videos         |
| NewPipe         | Android     | Descargar sin premium    |
| youtube-dl      | CLI         | Descargar desde terminal |

```bash
# Descargar video con youtube-dl
youtube-dl -f best "https://www.youtube.com/watch?v=VIDEO_ID"

# Solo audio (para escuchar)
youtube-dl -x --audio-format mp3 "URL"
```
