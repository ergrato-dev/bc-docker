# Proyecto Semana 03 - Starter Files

Este directorio contiene los archivos iniciales para el proyecto.

## Contenido

```
starter/
├── config/
│   ├── app.env      # Variables para la API
│   └── db.env       # Variables para MySQL
├── scripts/
│   ├── health-check.sh  # Script de verificación de salud
│   └── monitor.sh       # Script de monitoreo (TODO)
└── web/
    └── index.html       # Página de estado
```

## Instrucciones

1. Copia este directorio a tu área de trabajo
2. Completa los archivos marcados con `# TODO:`
3. Sigue las instrucciones del README.md principal

## Comandos de inicio

```bash
# Copiar a directorio temporal
cp -r starter /tmp/monitoring-project
cd /tmp/monitoring-project

# Ver estructura
find . -type f
```
