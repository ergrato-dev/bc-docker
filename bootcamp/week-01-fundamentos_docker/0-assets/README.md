## 🎨 Paleta de Colores

Los diagramas utilizan la paleta oficial de Docker y colores complementarios:

| Color          | Hex       | Uso                                 |
| -------------- | --------- | ----------------------------------- |
| Docker Blue    | `#2496ED` | Elementos principales de Docker     |
| Success Green  | `#51cf66` | Estados running, acciones positivas |
| Warning Yellow | `#ffd43b` | Estados paused, advertencias        |
| Error Red      | `#ff6b6b` | Estados stopped, errores            |
| Background     | `#1a1a2e` | Fondo oscuro                        |
| Secondary      | `#2d2d44` | Cajas secundarias                   |
